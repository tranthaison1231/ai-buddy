# AI Buddy Changelog

## [Initial Version] - {PR_MERGE_DATE}

- **Buddy Translate**: Instant Vietnamese ⇄ English translation with dictionary cards, IPA pronunciation, and macOS speech playback.
- **Buddy Draft Reply**: Draft context-aware replies with iterative refinement via custom ideas.
- **Buddy Polish English**: Refine English drafts with grammar explanations and lessons, supporting both popup review and immediate in-place replacement.
- **Buddy Write**: Expand rough shorthand notes or bullet points into ready-to-send chat messages or emails with style and language controls.
- **Buddy Summarize**: Condense long chat threads, emails, or documents into TL;DR, key points, and action items.
- **Buddy Ask**: Fast multi-turn AI Q&A with optional selected-text context and quick presets.
- **Buddy Vision**: Capture a screen region, clipboard image, or image file to explain, extract text (OCR), translate, or summarize.
- **Buddy Home**: Central hub with guides, custom prompt editor, settings overview, and quick launch for all commands.
- Multi-provider support for **Google Gemini**, **Groq**, **OpenAI**, and any **Custom** OpenAI-compatible endpoint (including local Ollama).
